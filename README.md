# futobi-labs.github.io

Home page for **https://labs.tannerspaulding.com**, the Futobi Labs home (Test Print look). `futobi/descent.html` is the Descent prototype shown in its live window. Published by GitHub Pages straight from the `main` branch. The `CNAME` file sets the custom domain.

The labs are separate repos in this organization and appear under this domain automatically as project sites:

- [Data Viz Lab](https://github.com/futobi-labs/dataviz-lab) at `/dataviz-lab/`
- [Data Model Lab](https://github.com/futobi-labs/datamodel-lab) at `/datamodel-lab/`

To add a lab: create a public repo in this organization, publish it with GitHub Pages, and add a plate to `index.html`.
